The method behind these apps

All of the apps, the public and the private ones, are built with my own development templates: coding standards, a reference for every AL object type generated from the AL compiler itself, design patterns (polymorphic table logic, per-feature setup and assisted setup, demo data packages, MCP configurations), analyzer rulesets, documentation and testing standards, and checklists. There are three variants, for greenfield products, customer projects and NAV reimplementations. I improve them with every project, and they are what I bring to a team.
