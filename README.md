# bc-knowledge-graph

A Neo4j knowledge graph of Microsoft Dynamics 365 Business Central products: AL objects, the standard
objects and events they touch, features, tests, and the API contracts that connect AL extensions to the
systems around them.

It answers questions that are hard to answer by reading repositories one at a time:

- Which standard tables, fields and events are touched by more than one of my apps?
- Which contract operations have no AL implementation yet?
- If a contract property changes, which AL API field and which BC table field are affected?
- Which features have no tests?

Status: under construction.
